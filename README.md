# HealthMart Analytics Platform

A modern end-to-end Analytics Engineering project simulating a healthcare retail company.

---

## Project Goal

To design and build a complete analytics platform for **HealthMart**, a fictional healthcare retail company (similar to CVS/Walgreens).

This project simulates real-world Analytics Engineering work including:

- Data modeling (Kimball star schema)
- Data warehousing (BigQuery)
- Transformations (dbt)
- Data orchestration (Airflow - later phase)
- Analytics dashboards (Power BI)
- Data engineering best practices (Git, documentation, testing)

---
